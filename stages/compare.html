Procedures used

compare-periods

Subtract the period at a small swing from the period at a large swing.

Inputs: large, small

Method text

start stage Compare by researcher from state [
  set information to [set large-period to 2.01 set small-period to 2.00 set unit to "s"]
]
  about "Compare the two periods. A difference within the timing uncertainty
  does not support the starting hypothesis."
  do compare-periods with [
    large at large-period of information
    small at small-period of information
  ] into difference of information
end stage with state [
  set information to [
    set large-period to 2.01
    set small-period to 2.00
    set unit to "s"
    set difference to unknown
  ]
]
